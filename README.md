# taiwan-hems-simulator
台灣家庭能源管理（HEMS）模擬器：以 pvlib 在地日照、規則式/MILP 策略逐時調度太陽能+電池+市電，估算自用率/自給率/年電費/回本年限，支援餘電躉售與面積分階段設計。Taiwan home energy management (HEMS) simulator: pvlib-based solar, rule-based/MILP dispatch of PV + battery + grid, computing self-consumption/self-sufficiency/annual bill/payback, with feed-in tariff and roof-area staged design analysis.
