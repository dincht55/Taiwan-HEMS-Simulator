# 03 — 電池與充放電模型（模組 3、4 共用）

> 電池行為唯一來源。數值（容量、效率、SOC 限、功率限、衰減成本）見 `.env`，本檔只用符號。

## 1. SOC 動態方程（離散時步）

設時步 Δt（小時）= `SIM_TIMESTEP_MIN` / 60，電池可用容量 `E_cap` = `BATT_CAPACITY_KWH`：

```
SOC(t+1) = SOC(t) + [ η_ch × P_ch(t) − P_dis(t) / η_dis ] × Δt / E_cap
```

- `P_ch`：充電功率（自外部流入電池前的功率，效率 `η_ch` 後才進電芯）
- `P_dis`：放電功率（電芯輸出 / `η_dis` 才是對外可用功率）
- `η_ch` = `BATT_CHARGE_EFF`、`η_dis` = `BATT_DISCHARGE_EFF`
- 往返效率 = `η_ch × η_dis`

## 2. 約束（BMS 行為）

```
SOC_min ≤ SOC(t) ≤ SOC_max           # BATT_SOC_MIN / BATT_SOC_MAX，保護壽命
0 ≤ P_ch(t)  ≤ BATT_MAX_CHARGE_KW
0 ≤ P_dis(t) ≤ BATT_MAX_DISCHARGE_KW
不可同時充放：P_ch(t) × P_dis(t) = 0   # 規則式天然滿足；MILP 用二元變數強制（見 docs/05）
```

充電時還受「離 SOC_max 還有多少空間」限制；放電時受「離 SOC_min 還有多少可放」限制。
BMS 行為 = 把請求功率夾在上述上下限內（clamp），回報「實際」吸收/釋放功率。

## 3. 充電來源優先序（模組 3）

充電能量的來源依成本由低到高：

```
1) 太陽能餘電（pv_to_batt）   ← 最優先，邊際成本≈0，避免外送/棄電
2) 市電離峰補充（grid_to_batt）← 僅在「離峰時段」且「預測太陽能不足以撐過尖峰」時
```

> 市電充電是否值得：只有當「離峰購電價 + 往返損耗成本 + 衰減成本 < 尖峰購電價」才有套利空間。
> 在台灣三段式下尖離峰價差大，通常成立；但務必把 §5 衰減成本算進去。

## 4. 充電曲線簡化

真實鋰電為 CC-CV（定電流→定電壓，尾段降功率）。模擬可分兩級：

- **初版（夠用）**：定功率充電，受最大充電功率與剩餘容量夾限。
- **進階**：當 SOC 高於某門檻（如 90%）線性降功率，近似 CV 尾段。

## 5. 電池衰減成本（務必納入最佳化）

避免模型無腦狂充放。兩種模型擇一：

- **吞吐量法（簡單，建議初版）**：
  ```
  衰減成本 = BATT_DEGRADATION_COST × (P_ch + P_dis) × Δt
  ```
  `BATT_DEGRADATION_COST`（元/kWh 吞吐）≈ 電池單價 ÷ (總可循環吞吐量 kWh)。
- **循環計數法（進階）**：用 rainflow 演算法數等效循環數，套循環壽命曲線；較準但較複雜。

此成本會進入 docs/05 的目標函數；規則式策略也可用它做「是否值得放電」的門檻判斷。

## 5.1 介面對應（詳見 docs/01 §4）
- `charge_step(...)`：吸收功率，受 §2 約束，更新 SOC。
- `discharge_step(...)`：釋放功率供負載，受 §2 約束，更新 SOC。
- 兩者都回傳「實際」功率（可能小於請求值）與新 `BatteryState`。
