# 05 — 調度策略、最佳化與驗證

> 控制邏輯與評估公式唯一來源。符號數值見設定物件（`config.py`，可由 `.env` 覆寫），時段見 `04`，電池見 `03`。

## 1. 規則式控制（rule_based）— 自用優先決策階梯

對應 `SIM_CONTROL_STRATEGY=rule_based`，每個時步依序判斷：

```
1. 太陽能優先供當下負載（pv_to_load = min(pv, load)）。
2. 若太陽能 > 負載（有餘電）：餘電充電池；電池滿了才 → 饋電/限發（台灣多為限發 curtail）。
3. 若太陽能 < 負載（缺口）：
   a. 現在是貴時段（peak/mid）→ 電池放電補缺口；電池見底才用市電。
   b. 現在是離峰（offpeak）→ 直接用市電供負載；
      且若電池未滿、且預測明日太陽能不足以撐過尖峰 → 用市電把電池補到目標 SOC。
```

優點：免預測、運算輕、最穩健（商用系統預設）。缺點：短視，無法跨時段最佳化。
第 3b 的「預測」是規則式與最佳化的分水嶺。

## 2. 最佳化控制（milp_mpc）— MILP 目標函數

對應 `SIM_CONTROL_STRATEGY=milp_mpc`。用未來視窗（如 24h）的太陽能與負載預測，求整段電費最低。

**目標函數（最小化淨成本）：**
```
min  Σ_t [ c_buy(t)·P_grid,in(t) − c_sell·P_grid,out(t) + c_deg·(P_ch(t)+P_dis(t)) ] · Δt
```
- `c_buy(t)`：購電價（`04` 的 `get_price`）
- `c_sell` = `TARIFF_SELL_PRICE`（台灣自用型≈0，賣電項幾乎無作用）
- `c_deg` = `BATT_DEGRADATION_COST`（務必納入，否則高估效益）

**約束：**
```
功率平衡： P_pv(t)+P_grid,in(t)+P_dis(t) = P_load(t)+P_grid,out(t)+P_ch(t)+P_curtail(t)
SOC 動態： SOC(t+1)=SOC(t)+[η_ch·P_ch(t)−P_dis(t)/η_dis]·Δt/E_cap      （見 `03`）
SOC 範圍： BATT_SOC_MIN ≤ SOC(t) ≤ BATT_SOC_MAX
功率上限： 0≤P_ch(t)≤BATT_MAX_CHARGE_KW·u(t)
          0≤P_dis(t)≤BATT_MAX_DISCHARGE_KW·(1−u(t))
          u(t)∈{0,1}                          # 二元：禁止同時充放 → 這就是 MILP 的整數來源
```

實作建議：用 `pulp` 建模；變數為各時步的 `P_ch/P_dis/P_grid,in/P_grid,out/SOC` 與二元 `u`。

**MPC 滾動執行：** 每個時步用最新預測重解上式，只採用「本時步」的指令，下一步再重算，
藉此吸收預測誤差。最佳實務常用「兩層式」：上層 MILP 規劃、下層規則式即時補償。

## 3. 評估指標（compute_metrics）

```
自用率 SCR = 被自用的太陽能能量 / 太陽能總發電量
自給率 SSR = 自家供應的負載能量 / 總負載
          = (總負載 − 向市電購電) / 總負載
年省電費  = 基準情境電費 − 本策略電費
          （基準 = 無儲能、或純規則式，作為對照）
```

經濟指標（年化）：
```
回本年限 ≈ 系統建置淨成本 / 年省電費        # 淨成本可扣補助
NPV  = Σ_y 年現金流 / (1+r)^y − 初始投資
IRR  = 使 NPV = 0 的折現率 r
LCOS = 系統全生命週期成本 / 全生命週期放電量（元/kWh）
```

> 提醒：SCR 與 SSR 呈線性關係；自給率在不過度超配下難超過約 80%，且自用率對 PV/電池容量
> 呈漸近（邊際遞減）。故「電池越大越划算」並不成立——容量配置要在 §4 用回測找甜蜜點。

## 4. 驗證方式

1. **逐時回測**：用整年實際負載 + 在地日照（TMY/實測），以 `SIM_TIMESTEP_MIN` 解析度跑全年。
2. **對照基準**：並列「無儲能」「純規則式」「MILP/MPC」三種，比 SCR/SSR/年電費。
3. **參數掃描**：對 PV 容量、電池容量、充電門檻做網格掃描（用 `multiprocessing` 平行），
   找回本最短或 NPV 最大的配置。
4. **不變式檢查**：每時步驗證 `01` §3 的功率平衡殘差≈0，作為單元測試。
5. **外部工具交叉驗證**（選用）：pvlib（發電）、NREL SAM/PySAM（系統+財務）做 sanity check。

## 5. 策略選擇建議（台灣情境）

- 想快速可用：先做 `rule_based`，能拿到約八成效益。
- 想求最佳：加 `milp_mpc`（兩層式）；務必含 `c_deg`，賣電項設 0。
- 配置原則：以「吃滿白天餘電 + 撐過傍晚尖峰」為準，別為追高自給率而超配。
