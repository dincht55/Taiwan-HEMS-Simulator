# 04 — 台電電價、時段定義與計費公式

> 「電價時段（小時定義）」與「計費公式」的唯一來源。
> ⚠️ 各時段的**費率數字**不在此檔，住在設定物件（`config.py` 的 `TARIFF_PEAK/MID/OFFPEAK/BASIC_FEE/SELL_PRICE`，可由 `.env` 覆寫）。
> ⚠️ 費率約每年 4 月、10 月由台電調整；分析時務必提醒使用者向台電官網確認最新值。

## 1. 兩大計費方式

- **累進電價（progressive）**：依「用電量」分段累進，與用電時段無關（全台多數住宅預設）。
- **時間電價（time-of-use）**：分尖離峰計價，價差大；須向台電申請。
  - 申請門檻：住宅每月用電約 700 度以上較可能划算（可向台電 App / 1911 / 服務據點辦理）。
  - 本專案的削峰填谷與儲能套利，**前提是用戶已採時間電價**。

設定項 `TARIFF_SCHEME` 可選：`progressive` / `two_stage` / `three_stage`。

## 2. 時段定義（小時，本檔為唯一規格；程式應依此建常數表）

> 以下為「住商型簡易時間電價」的一般結構；夏月為 6/1–9/30。
> 週六、週日多為半尖峰/離峰，初版模擬可先以「平日定義」為主，假日全時段以離峰近似並註明。

### 三段式（three_stage）
| 時段 | 夏月（平日） | 非夏月（平日） | 對應設定費率 |
|------|--------------|----------------|----------------|
| 尖峰   | 16:00–22:00 | （非夏月無尖峰） | `TARIFF_PEAK` |
| 半尖峰 | 09:00–16:00、22:00–24:00 | 06:00–11:00、14:00–24:00 | `TARIFF_MID` |
| 離峰   | 00:00–09:00 | 00:00–06:00、11:00–14:00 | `TARIFF_OFFPEAK` |

### 二段式（two_stage）
| 時段 | 夏月（平日） | 對應設定費率 |
|------|--------------|----------------|
| 尖峰 | 09:00–24:00（簡化）| `TARIFF_PEAK` |
| 離峰 | 00:00–09:00 | `TARIFF_OFFPEAK` |

> 上表時段為實作起點；正式分析請以台電當期公告為準，並把實際時段參數化以便調整。

## 3. 計費公式

```
月電費 = 基本電費 + 流動電費 [ + 累進加計（高用量級距，視方案）]
基本電費 = TARIFF_BASIC_FEE
流動電費 = Σ_時段 ( 該時段用電度數 × 該時段單價 )
```

模擬層級的逐時購電成本：

```
時步購電成本 = grid_in_kw × Δt(小時) × price(t)
時步售電收益 = grid_out_kw × Δt(小時) × TARIFF_SELL_PRICE   # 台灣自用型通常為 0
```
