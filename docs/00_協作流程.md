# 00 — 協作流程（Claude Projects 專用）

> 本檔是「在 Projects 對話中如何逐層開發 HEMS 模擬器」的唯一來源。
> 領域細節見 01–05；本檔只談**協作方式、驗收標準、Projects 環境差異**，不重述模型公式。
> （原 CLAUDE.md 是給 Claude Code 用的；在 Projects 中以「專案指令」+ 本檔為準。）

---

## 1. Projects 與 Claude Code 的環境差異（先讀，避免誤會）

| 項目 | Claude Code | Claude Projects（本專案） |
|------|-------------|---------------------------|
| 檔案系統 | 有持久沙箱，可 `bash setup.sh` 真的建檔執行 | 對話式，無長期掛載的專案資料夾 |
| `.env` | 真的讀檔 | 對話中無法持久掛載；見 §2 的替代做法 |
| 套件安裝 | `setup.sh` 實際安裝 | 不需安裝；程式碼交付後由使用者在本機 Windows 執行 |
| 產出 | 直接寫入 `src/` | 以「完整檔案」形式回覆，使用者自行存成 `.py` |

> 因此在 Projects 中：**不要嘗試執行 `setup.sh` 或讀 `.env`**。改用 §2 的設定交付方式，
> 並以「完整、可直接存檔執行」的檔案交付每支模組。

---

## 2. 設定的交付方式（取代對話中無法掛載的 .env）

維持「設定與程式分離」的單一來源原則，但落地方式改為二選一：

- **方式 A（建議）**：產出一支 `config.py`，內含與 `.env.example` 對應的預設值（繁中註解、type hints），
  並保留「若偵測到 `.env` 則優先讀取」的邏輯（用 `python-dotenv`，本機執行時仍可用 `.env` 覆寫）。
- **方式 B**：使用者把參數貼在訊息裡，Claude 以該批參數產生對應結果。

無論哪種，**程式內仍不得散落硬編碼魔術數字**；所有數值集中在 `config.py` 或傳入的設定物件。
數值清單與單位以 `01_系統架構` 的 `AppConfig` 欄位為準，不在本檔重抄。

---

## 3. 逐層開發順序（嚴格由下而上）

一次只專注一支模組，通過該模組的「驗收清單」(§4) 後，再往上層堆疊：

```
electrical_base → solar_pv → battery_charge → power_dispatch → hems_simulation
（含 config.py）   （含太陽能模型）  （含 SOC）      （含調度）      （整合 + 指標）
```

每支模組交付時請附：完整檔案 + `__main__` 最小示範 + 對應 `pytest` 測試片段。

---

## 4. 各模組驗收清單（Definition of Done）

完成每支模組前，逐項自我檢查並在回覆中簡述通過情形：

### 共通（每支都要）
- [ ] 全程繁體中文註解；每個函式有 docstring（用途/參數/回傳/**單位**）。
- [ ] 變數名帶單位（`*_kw`、`*_kwh`、`*_min`）；無單位混用。
- [ ] 全面 type hints；無硬編碼魔術數字（數值來自設定物件）。
- [ ] 可單獨執行（`__main__` 示範）；公開函式有 pytest 測試。
- [ ] 只 import 更低層模組（符合相依方向，無循環 import）。

### 1. config.py + electrical_base
- [ ] `load_config()` 能由預設值（及選用 `.env`）產生 `AppConfig`。
- [ ] 功率↔能量換算、效率套用、功率平衡殘差函式皆有測試，殘差≈0。

### 2. solar_pv
- [ ] pvlib 路徑可跑；另提供無網路時的簡化發電模型並標明精度較低。
- [ ] 回傳每時步 `pv_kw`（交流端、已扣系統損耗與逆變器效率）；時區正確。

### 3. battery_charge
- [ ] SOC 動態方程、SOC 上下限與最大充電功率夾限正確。
- [ ] 充電來源優先序（太陽能餘電 > 離峰市電）落實；充電效率計入。
- [ ] 衰減成本可輸出，供上層最佳化/門檻判斷使用。

### 4. power_dispatch
- [ ] 規則式自用優先決策階梯（見 05 §1）逐時正確。
- [ ] 放電受 SOC 下限與最大放電功率夾限；放電效率計入。
- [ ] 單一時步回傳所有功率分配欄位（對應 01 §3 資料契約）。

### 5. hems_simulation
- [ ] 時間迴圈 + 策略切換（rule_based / milp_mpc）。
- [ ] 每時步功率平衡不變式成立（單元測試覆蓋）。
- [ ] `compute_metrics` 輸出 SCR/SSR/年省電費/回本年限（公式見 05 §3）。
- [ ] 結果輸出 CSV + matplotlib 圖；印出摘要。

## 5. 回覆與協作規範

- 交付程式時給**完整可執行檔案**，非片段；修改時也回完整檔，並標註改動處。
- 規格有歧義先問我再動工，不要自行臆測關鍵設計（如耦合架構、時段邊界）。
- 引用領域細節時指向對應知識檔（如「依 04 §2 時段表」），不複製整段內容。
- 涉及電價/經濟試算時，提醒費率會變動、結果為決策參考非投資建議。
- 若我貼出執行錯誤訊息，針對該訊息做最小修正並回完整檔，不重寫無關部分。
