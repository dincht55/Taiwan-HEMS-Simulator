# 02 — 基本電學與太陽能模型（模組 1、2）

> 模型原理唯一來源。本檔只用符號與公式。

## 1. 基本電學量與單位

| 量 | 符號 | 單位 | 關係 |
|----|------|------|------|
| 功率 | P | W / kW | P = V × I（直流）|
| 能量 | E | Wh / kWh | E = P × t |
| 電壓 | V | V | — |
| 電流 | I | A | — |

換算：`1 kW = 1000 W`、`1 kWh = 1 kW 持續 1 小時`、
`某時步能量(kWh) = 功率(kW) × 時步(分鐘) / 60`。

> 本專案內部一律以 **kW / kWh / 分鐘** 為單位（見 `00_開發指南` §5）。

## 2. 轉換效率與功率平衡

每經過一級電力電子轉換（DC-DC、DC-AC、AC-DC），功率乘上該級效率：

```
P_out = P_in × η          （0 < η ≤ 1）
```

往返效率（round-trip）= 充電效率 × 放電效率（電池見 docs/03）。

**節點功率平衡式**（任一時步都須成立，對應 docs/01 §3 不變式）：

```
P_pv + P_grid,in + P_batt,dis  =  P_load + P_grid,out + P_batt,ch + P_curtail
（輸入端）                          （輸出端）
```

## 3. DC 耦合 vs AC 耦合（決定要乘哪些效率）

太陽能存入電池的轉換鏈不同，模組 3/4 計算效率時要依架構選對鏈：

| 架構 | 太陽能→電池路徑 | 轉換次數 | 效率特性 |
|------|----------------|----------|----------|
| **DC 耦合** | PV → MPPT(DC-DC) → 電池 | 1 次 | 高（約 98–99%/級）；混合逆變器整合 |
| **AC 耦合** | PV → 逆變器(DC-AC) → 電池逆變器(AC-DC) → 電池 | 2 次 | 較低；但易加裝於既有太陽能 |

本模擬預設以 **DC 耦合** 計（太陽能→電池只乘一次充電效率）。若要模擬 AC 耦合，
在太陽能→電池路徑額外乘上逆變器效率與 AC-DC 效率。建議用一個 `coupling: str` 參數切換。

## 4. 太陽能模型（模組 2）

### 4.1 首選：pvlib 流程

```
1. Location(latitude, longitude, tz, altitude)            ← .env
2. 太陽位置 solarposition.get_solarposition(times, ...)
3. 輻照來源：
   - 有 TMY/實測：讀檔（GHI/DNI/DHI）
   - 無資料：clearsky.ineichen() 產生晴空輻照（樂觀上界，需註明）
4. 傾斜面輻照 POA：irradiance.get_total_irradiance(tilt, azimuth, ...)   ← .env 傾角方位
5. 直流發電：pvlib.pvsystem.pvwatts_dc() 或 PVWatts 模型（用 PV_CAPACITY_KWP）
6. 交流端：乘 PV_INVERTER_EFF；整體再乘 (1 - PV_SYSTEM_LOSS)
```

回傳每時步 `pv_kw`（交流端、已扣損耗）。注意時區與日光對齊（用在地時間）。

### 4.2 退回：簡化模型（無 pvlib / 離線）

以晴空鐘形近似，供快速測試（精度低，須標明）：

```
日出~日落之間：
  f(t) = max(0, sin(π × (t - t_sunrise) / (t_sunset - t_sunrise)))
  pv_kw(t) = PV_CAPACITY_KWP × f(t) × (1 - PV_SYSTEM_LOSS) × PV_INVERTER_EFF
其餘時間 pv_kw = 0
```

`t_sunrise/t_sunset` 可用 pvlib 或天文公式估算；夏季日照較長。

### 4.3 注意事項
- 中午為發電高峰、清晨傍晚低；與負載/電價尖峰（傍晚）常不重疊，正是需要電池的原因。
- clearsky 是無雲上界，真實會更低；做經濟分析建議用 TMY 或實測輻照。
- 溫度會降低效率（高溫減發電）；簡化模型已併入 `PV_SYSTEM_LOSS`，精算可用 pvlib 溫度模型。
