# 00 — 開發指南與架構準則

> 本檔說明專案的**架構準則、開發順序、模組驗收與程式碼規範**，供貢獻者參考。
> 領域模型細節見 01–07；本檔不重述公式。

---

## 1. 架構總覽

五模組**單向相依**（低層不知道高層存在，無循環 import）：

```
electrical_base → solar_pv → battery_charge → power_dispatch → hems_simulation
（config.py 為所有層共用的單一設定來源；fast_core.py 為 numba JIT 調度核心）
```

`hems_simulation` 為唯一協調者，向下 import 全部更低層模組。介面與資料契約見 `01_系統架構`。

---

## 2. 單一設定來源

- 一切可調數值集中在 **`config.ini`**，由 `config.py` 的 `load_config()` 讀成唯讀的 `AppConfig`，
  啟動後唯讀往下傳遞。程式其他地方**不得散落硬編碼魔術數字**。
- 本機可選用 `.env` 臨時覆寫（透過 python-dotenv，`load_config(use_dotenv=True)`）。
- 欄位名稱、單位與 `01_系統架構` 的 `AppConfig` 一致；費率時段見 `04`/`06`。

---

## 3. 逐層開發順序（由下而上）

一次專注一支模組，通過該模組「驗收清單」(§4) 後再往上層堆疊：

```
config.py + electrical_base → solar_pv → battery_charge → power_dispatch → hems_simulation
```

每支模組應附：完整檔案 + `__main__` 最小示範 + 對應 pytest（集中於 `tests/test_hems.py`）。

---

## 4. 各模組驗收清單（Definition of Done）

### 共通（每支都要）
- [ ] 全程繁體中文註解；每個函式有 docstring（用途/參數/回傳/**單位**）。
- [ ] 變數名帶單位（`*_kw`、`*_kwh`、`*_min`）；無單位混用。
- [ ] 全面 type hints；無硬編碼魔術數字（數值來自設定物件）。
- [ ] 可單獨執行（`__main__` 示範）；公開函式有 pytest 測試。
- [ ] 只 import 更低層模組（符合相依方向，無循環 import）。

### 1. config + electrical_base
- [ ] `load_config()` 能由 `config.ini`（及選用 `.env`）產生 `AppConfig`。
- [ ] 功率↔能量換算、效率套用、功率平衡殘差函式皆有測試，殘差≈0。

### 2. solar_pv
- [ ] pvlib 路徑可跑；另提供無網路時的簡化發電模型並標明精度較低。
- [ ] 回傳每時步 `pv_kw`（交流端、已扣系統損耗與逆變器效率）；時區正確。
- [ ] 可載入在地氣候平年值（`data/climate_normals.csv`），否則退回內建預設。

### 3. battery_charge
- [ ] SOC 動態方程、SOC 上下限與最大充電功率夾限正確。
- [ ] 充電來源優先序（太陽能餘電 > 離峰市電）落實；充電效率計入。
- [ ] 衰減成本可輸出，供上層最佳化/門檻判斷使用。

### 4. power_dispatch
- [ ] 規則式自用優先決策階梯（見 `05` §1）逐時正確。
- [ ] 放電受 SOC 下限與最大放電功率夾限；放電效率計入。
- [ ] 單一時步回傳所有功率分配欄位（對應 `01` §3 資料契約）。

### 5. hems_simulation
- [ ] 時間迴圈 + 策略切換（rule_based / rule_based_forecast / milp_mpc）。
- [ ] 每時步功率平衡不變式成立（單元測試覆蓋）。
- [ ] `compute_metrics` 輸出 SCR/SSR/年省電費/回本年限（公式見 `05` §3）。
- [ ] 結果輸出 CSV + matplotlib 圖；印出摘要。

---

## 5. 程式碼規範

- 交付完整可執行檔案（非片段）。
- 全程繁體中文註解；每個函式 docstring 標明用途/參數/回傳/單位。
- 單位標註於變數名（`*_kw`、`*_kwh`、`*_min`），嚴禁單位混用。
- 全面 type hints；無硬編碼魔術數字（數值來自 `config.ini` / `AppConfig`）。
- 向量化優先；大量模擬用 numba JIT（`fast_core.py`）+ multiprocessing 吃滿多核。
- 每支模組可單獨執行（`__main__` 示範），公開函式附 pytest。
- 涉及電價/經濟試算時，標明費率會變動、結果為決策參考非投資建議。
