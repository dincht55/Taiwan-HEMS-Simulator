# 01 — 系統架構、模組 API 與資料契約

> 本檔是「模組介面與資料流」的唯一來源。數值見設定物件（`config.py`，可由 `.env` 覆寫）；本檔不重述。

## 1. 設計原則

- 五模組單向相依（見 `00_開發指南` §1），低層不知道高層存在。
- 一切可調數值來自設定物件 `AppConfig`（`config.py` 內含預設值，可由 `.env` 覆寫），於程式啟動時載入後唯讀往下傳遞。
- 時間序列資料一律用 `pandas.DataFrame`（`DatetimeIndex`），所有模組共用同一份欄位契約。

## 2. 設定物件 AppConfig（建議）

從設定物件讀入後封裝；欄位對應 `config.py` 的設定項（同名可由 `.env` 覆寫；數值不在此重抄，只列名稱與單位）：

```python
from dataclasses import dataclass

@dataclass(frozen=True)
class AppConfig:
    # 位置
    latitude: float          # HEMS_LATITUDE  (度)
    longitude: float         # HEMS_LONGITUDE (度)
    timezone: str            # HEMS_TIMEZONE
    altitude: float          # HEMS_ALTITUDE  (m)
    # 太陽能
    pv_capacity_kwp: float   # PV_CAPACITY_KWP
    pv_tilt_deg: float       # PV_TILT_DEG
    pv_azimuth_deg: float    # PV_AZIMUTH_DEG
    pv_system_loss: float    # PV_SYSTEM_LOSS  (0~1)
    pv_inverter_eff: float   # PV_INVERTER_EFF (0~1)
    # 電池
    batt_capacity_kwh: float # BATT_CAPACITY_KWH
    batt_soc_min: float      # BATT_SOC_MIN
    batt_soc_max: float      # BATT_SOC_MAX
    batt_max_charge_kw: float    # BATT_MAX_CHARGE_KW
    batt_max_discharge_kw: float # BATT_MAX_DISCHARGE_KW
    batt_charge_eff: float   # BATT_CHARGE_EFF
    batt_discharge_eff: float# BATT_DISCHARGE_EFF
    batt_deg_cost: float     # BATT_DEGRADATION_COST (元/kWh 吞吐)
    # 電價（數值；時段定義見 `04`）
    tariff_scheme: str       # TARIFF_SCHEME
    tariff_basic_fee: float  # TARIFF_BASIC_FEE
    tariff_sell_price: float # TARIFF_SELL_PRICE
    tariff_peak: float       # TARIFF_PEAK
    tariff_mid: float        # TARIFF_MID
    tariff_offpeak: float    # TARIFF_OFFPEAK
    # 模擬
    timestep_min: int        # SIM_TIMESTEP_MIN
    start_date: str          # SIM_START_DATE
    sim_days: int            # SIM_DAYS
    control_strategy: str    # SIM_CONTROL_STRATEGY
    load_profile_csv: str    # LOAD_PROFILE_CSV
```

建議在獨立的 `config.py` 提供 `load_config() -> AppConfig`：內含預設值，若偵測到 `.env` 則優先讀取覆寫。
（上方各欄位註解中的大寫名稱為設定鍵名，`config.py` 預設值與 `.env` 兩邊同名共用。）

## 3. 共用時間序列資料契約

主模擬 DataFrame，索引為 `DatetimeIndex`（間隔 = `SIM_TIMESTEP_MIN`）。功率欄位為「該時步的平均功率 kW」，能量 = 功率 × Δt。

| 欄位            | 單位 | 意義 |
|-----------------|------|------|
| `pv_kw`         | kW   | 太陽能可發功率（模組 2 產生）|
| `load_kw`       | kW   | 家庭負載（由 `LOAD_PROFILE_CSV` 載入）|
| `price`         | 元/度| 該時步購電單價（模組查 `04` 計價）|
| `soc`           | 0~1  | 時步「結束」時的電池 SOC |
| `batt_ch_kw`    | kW   | 電池充電功率（流入電池，正值）|
| `batt_dis_kw`   | kW   | 電池放電功率（流出電池，正值）|
| `grid_in_kw`    | kW   | 自市電購入功率 |
| `grid_out_kw`   | kW   | 餘電饋入市電功率（台灣自用型通常 0）|
| `pv_to_load_kw` | kW   | 太陽能直供負載 |
| `pv_to_batt_kw` | kW   | 太陽能充電池 |
| `pv_curtail_kw` | kW   | 限發/棄電（電池滿且不外送時）|

> 不變式（每個時步都須成立）：
> `pv_kw + grid_in_kw + batt_dis_kw == load_kw + grid_out_kw + batt_ch_kw + pv_curtail_kw`

## 4. 各模組建議公開 API

以下為函式簽章「契約」，CC 實作時可微調但須維持語意與單位。

### 模組 1：electrical_base.py
```python
def kwh(power_kw: float, minutes: float) -> float: ...        # 能量 = 功率×時間
def apply_efficiency(power_kw: float, eff: float) -> float: ...# 過一級轉換後的功率
def power_balance_residual(pv, grid_in, batt_dis, load, grid_out, batt_ch, curtail) -> float: ...
def load_config() -> "AppConfig": ...                         # 讀設定（config.py 預設值，可由 .env 覆寫）
```

### 模組 2：solar_pv.py
```python
def simulate_pv(cfg: AppConfig, index: pd.DatetimeIndex) -> pd.Series: ...
# 回傳每時步 pv_kw（交流端，已含系統損耗與逆變器效率）。
# 首選 pvlib；無網路時退回 `02` 的簡化模型。
```

### 模組 3：battery_charge.py
```python
@dataclass
class BatteryState:
    soc: float            # 目前 SOC (0~1)

def charge_step(state, available_kw, source: str, cfg, minutes) -> tuple[float, BatteryState]: ...
# 對電池充電一個時步；回傳 (實際吸收功率 kW, 新狀態)。
# 受 SOC_max、最大充電功率、充電效率限制。source ∈ {"pv","grid"}。
```

### 模組 4：power_dispatch.py
```python
def discharge_step(state, demand_kw, cfg, minutes) -> tuple[float, BatteryState]: ...
def dispatch_step(state, pv_kw, load_kw, price_period: str, cfg, minutes) -> dict: ...
# 對單一時步做「自用優先」調度，回傳該時步所有功率分配（對應 §3 欄位）。
# 規則式決策階梯見 `05` §1。
```

### 模組 5：hems_simulation.py
```python
def run_simulation(cfg: AppConfig) -> pd.DataFrame: ...   # 跑完整段，回傳 §3 的 DataFrame
def compute_metrics(df: pd.DataFrame, cfg: AppConfig) -> dict: ...  # SCR/SSR/電費/回本，公式見 `05`
def main() -> None: ...   # 讀設定 → 跑模擬 → 存 output/ → 印摘要
```

## 5. 全域執行流程（hems_simulation）

```
load_config()                          # 讀設定（config.py，可由 .env 覆寫）
建立 DatetimeIndex（start_date, sim_days, timestep_min）
load_kw  ← 讀 LOAD_PROFILE_CSV
pv_kw    ← solar_pv.simulate_pv()
state    ← BatteryState(初始 SOC)
for 每個時步 t:
    price_period ← `04` 計價（依時間判斷尖峰/半尖峰/離峰）
    if control_strategy == "rule_based":
        result ← power_dispatch.dispatch_step(state, pv[t], load[t], price_period, cfg, dt)
    elif control_strategy == "milp_mpc":
        result ← 解 `05` §2 的 MILP（滾動視窗），取本時步指令
    記錄 result 至 DataFrame
metrics ← compute_metrics(df, cfg)
存 output/（CSV + matplotlib 圖）並印摘要
```
